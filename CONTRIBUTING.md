# Contributing

Contributions to this repository are welcome.

## How to contribute

1. Open an issue to discuss a bug, improvement, or question.
2. Fork the repository and create a new branch for your change.
3. Make focused changes and keep the documentation clear and concise.
4. If you modify notebooks, ensure that the narrative cells remain understandable and consistent with the project goals.
5. Submit a pull request with a short explanation of the motivation and the changes introduced.

## Guidelines

- Prefer small, well-documented changes.
- Keep code readable and avoid unnecessary dependencies.
- Preserve reproducibility and clearly document any new steps or assumptions.
- When adding data or generated artifacts, ensure that the purpose is explained.

## Reporting issues

Please include:

- a short description of the problem,
- the relevant file or notebook,
- steps to reproduce the issue, and
- the expected versus actual behavior.

Thank you for helping improve this research repository.
